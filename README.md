# PvPZone：用能量墙把大地图圈成小图

纯服务器端的 Northstar 模组，客户端不用装。在地图上选几个三维坐标，按顺序连成面，就会生成一道实体能量墙。墙可以竖着、斜着、水平（当天花板或地板），任何角度都行，坐标直接写在 `mod.json` 里。

> **状态：0.3.0，没有在游戏里跑过。** 这个环境没有游戏，也没有 Squirrel 编译器，用到的接口都和北极星源码核对过。第一次请开私人比赛测试，有报错就把控制台里 `[PvPZone]` 开头的行和错误信息发给我。

## 能量墙

| 特性 | 说明 |
|---|---|
| 形状 | 每个面由 3 个以上的三维坐标按顺序围成。所有点在同一平面上时，按一个平面铺满；不在同一平面时，以第一个点为中心切成三角形分别铺，所以每个点都严格落在墙上。 |
| 无法穿过 | 每一块都是带真实碰撞的实体，碰撞分组保持默认。铁驭、泰坦、AI、子弹、投射物和爆炸伤害都过不去，也会挡住 AI 的视线。 |
| 和普通墙一样 | 可以用钩爪抓、可以踩、可以站上去；能不能贴墙跑取决于模型表面（见下文）。 |
| 外观 | 默认用原版泰坦护罩球模型 `models/fx/xo_shield.mdl`，显示为半透明的蓝色能量护罩。颜色用 `pvpzone_wall_color` 设置。 |
| 出生点 | 和墙重叠的出生点会自动停用，不会出生在墙里。 |

### 关于模型（一定要看）

原版多人模式里，**没有现成的平板能量墙模型**：
- 战争游戏地图里的能量墙是地图本身的几何体和材质，不能拿出来单独生成。
- 原版 A 墙是一个特殊实体，只挡子弹，人可以穿过。
- `modelscale` 只放大外观，碰撞不会跟着变大，北极星源码里也写了这一点。

所以默认用护罩球来拼，规则是：
- 每个位置放上下两个半球，合成一个完整的球；球和球之间相互重叠，连成一道墙。
- 墙是封闭的，但**表面是一个个鼓包，厚度大约等于护罩球的直径**，所以不是严格的薄平面，贴墙跑的手感也不好。

要做出严格的薄平面墙，需要换一块**平板模型**，只要改 `mod.json`，不用改代码：
1. 用 Legion+ 在原版多人资源里找一个带碰撞、平整的板状模型，比如门板、金属墙板。
2. 把 `pvpzone_wall_model` 改成它的路径。
3. 把 `pvpzone_wall_thin_axis` 设成模型最薄的那根轴（`x`、`y` 或 `z`）。脚本会把这根轴对准墙面的法线，按模型实际尺寸铺满。
4. 加载地图后，日志里的 `[PvPZone] wall model ... size A x B x C` 会显示三根轴的尺寸，最小的那根就是薄轴。

如果原版找不到合适的模型，可以自己做一块平板模型，贴图引用原版的护罩材质。这样客户端也必须安装这个 mod。

## 配置坐标（mod.json）

每张多人地图都有一个配置项 `pvpzone_walls_<地图名>`：
- 每个点写成 `x y z`，点和点之间用逗号 `,` 隔开；
- 面和面之间用分号 `;` 隔开；
- 每个面至少 3 个点，按顺序沿着这个面的边缘走一圈。

```json
{ "Name": "pvpzone_walls_mp_wargames", "DefaultValue": "100 200 0, 900 200 0, 900 200 600, 100 200 600; 900 200 0, 900 900 0, 900 900 600, 900 200 600; 100 200 600, 900 200 600, 900 900 600, 100 900 600" }
```

上面这个例子（坐标是随便写的）有三个面：两面竖墙加一块水平天花板。

改完 `mod.json` 后要重新加载地图才会生效。只想调整某一个点，直接改那三个数字就行。

## 在游戏里取点（本机开私人比赛）

1. 控制台执行 `pvpzone_edit 1`，然后**重新加载地图**。
2. 用以下命令打点，打点时会画出黄色线段，持续 30 秒：
   - `pvpzone_add`：在准星对准的位置打点，可以打在地面、墙面或天花板上。
   - `pvpzone_addpos`：在当前眼睛所在的位置打点。要在半空中打点，先开 `sv_cheats 1` 再用 `noclip` 飞过去。
   - `pvpzone_undo`、`pvpzone_clear`：撤销上一个点、清空所有点。
3. `pvpzone_build`：用当前打的点**立刻生成一面预览墙**，可以马上走过去撞、开枪试。`pvpzone_unbuild` 删除所有预览墙。
4. `pvpzone_print`：在控制台输出这个面的坐标字符串，复制到 `mod.json` 对应地图的配置项里。已经有其他面时，前面加一个 `;`。
5. 然后 `pvpzone_clear`，接着做下一个面。
6. 正式开服前把 `pvpzone_edit` 改回 0。

## 其他可选功能（pvpzone_maps.nut）

- **脚本边界**（`PvPZone_SetBoundary`）：在平面上围一个区域作为兜底。墙没覆盖到的缺口，玩家一出去就会被拉回来。取点后用 `pvpzone_print boundary` 输出。
- **出界倒计时区**（`PvPZone_AddOOBZone`）：玩家进入后显示原版的"返回战场"倒计时，时间到了按出界死亡。取点后用 `pvpzone_print oob 5` 输出，5 表示秒数。需要先配置脚本边界才会生效。
- **自定义出生点**（`PvPZone_AddSpawn`）：用 `pvpzone_spawn` 输出。

## 控制台变量（ConVar）

| 变量 | 默认值 | 说明 |
|---|---|---|
| `pvpzone_enabled` | 1 | 总开关 |
| `pvpzone_edit` | 0 | 取点命令开关 |
| `pvpzone_walls` | 1 | 能量墙开关 |
| `pvpzone_wall_model` | models/fx/xo_shield.mdl | 墙块模型 |
| `pvpzone_wall_thin_axis` | none | 平板模型的薄轴（`x`、`y`、`z`）；`none` 表示圆形模型（护罩球） |
| `pvpzone_wall_spacing` | 0.9 | 墙块间距，按模型尺寸的比例算，越小重叠越多 |
| `pvpzone_wall_visible` | 1 | 0 = 隐形墙（碰撞仍然有效） |
| `pvpzone_wall_color` | 81 130 151 | 墙的颜色（R G B） |
| `pvpzone_wall_max_pieces` | 1500 | 墙块数量上限 |
| `pvpzone_walls_<地图名>` | 空 | 该地图的墙面坐标 |
| `pvpzone_warn_text` | 已到达对战区域边界 | 被脚本边界拉回时的提示文字 |
| `pvpzone_cull_props` / `pvpzone_cull_margin` | 0 / 3000 | 删除边界外远处的动态道具 |
| `pvpzone_farz` | 0 | 远裁剪距离（实验功能） |

## 性能

- 每块墙都是一个实体。用护罩球时，每个位置要放两块，一面 1000×500 的墙大约需要几十块，具体以日志里的数量为准。能量墙是半透明的，大面积铺开会掉帧。如果帧数不够，可以：设成隐形墙 `pvpzone_wall_visible 0`，或者换成尺寸更大的平板模型，或者减少墙的面积。
- 地图本身的静态几何是客户端自己渲染的，服务器端模组删不掉。

## 已知限制

- 墙块大小固定，边缘会比你选的点多出最多半块。网格是居中排列的，多出的部分平均分到两侧。
- 用护罩球时，墙是一层鼓包，不是薄平面（见上文"关于模型"）。
- 在 `mod.json` 里写很长的坐标字符串，有没有长度上限还没确认。如果墙面特别多导致读不全，告诉我，我再改成分多个配置项存。
